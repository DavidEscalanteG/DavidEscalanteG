# Recursos visuales

- **Cabecera:** composición tipográfica propia para el perfil de David Escalante / Deivee. El banner actual es SVG: el texto se convirtió en trazados y la referencia ilustrada a Umbreon, proporcionada por David, se vectorizó con curvas Bézier mediante Potrace. El trazado es una aproximación del PNG recibido; conserva la silueta, sus detalles y la firma visible, sin incrustar imágenes rasterizadas. La autoría de esa ilustración no se ha identificado en el material recibido. El personaje pertenece a sus titulares originales; no se atribuye su diseño a David. El PNG anterior se conserva como referencia.
- **Portadas de Kalin y Emoventure:** pantallas de inicio reales de los proyectos de equipo. La participación de David se describe en el README y no implica autoría de todas las ilustraciones o del proyecto completo.
- **Iconos:** [tandpfun/skill-icons](https://github.com/tandpfun/skill-icons), Godot-Dark.svg, Git.svg, CPP.svg y Python-Dark.svg. Se conserva su [licencia MIT](icons/LICENSE). Los archivos `tools-light.svg` y `tools-dark.svg` reúnen esos iconos y añaden sus nombres.

Todos los recursos que muestra el README se sirven desde este repositorio.
